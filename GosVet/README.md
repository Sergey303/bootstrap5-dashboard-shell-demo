# GosVet single-file demo

## Run

```bash
npm install
npm run dev
```

Dev URL: `http://localhost:5173`

## Build portable demo

```bash
npm run build
```

Expected artifact:

```text
dist/index.html
```

Routes:

- `index.html#/appointments/today`
- `index.html#/appointment/demo-001`
- `index.html#/external/retry/demo-001`
- `index.html#/attention`
- `index.html#/search`
